# PF2e Creature Size Matters

A Foundry VTT module for **Pathfinder 2e** that adds meaningful mechanical weight to size differentials in melee combat — bonus damage and a Reflex save when a larger creature hits a smaller one.

## Features

- Size category differential on melee hits (Tiny through Gargantuan)
- GM chat card with bonus damage, Reflex DC, and draggable failure conditions
- Configurable damage tiers, save DC, conditions, automation, and critical doubling
- **Post to Chat** Reflex checks so players roll their own saves with full bonuses
- Optional **Treat Small Player Characters as Medium** so ancestry size does not penalize PCs

## Install

In Foundry, open **Add-on Modules → Install Module** and paste the manifest URL:

```
https://github.com/esterlinej/pf2e-creature-size-matters/releases/latest/download/module.json
```

Or pick a version from [GitHub Releases](https://github.com/esterlinej/pf2e-creature-size-matters/releases).

Enable the module in your world (**Module Management**) and configure it under **Game Settings → Module Settings → PF2e Creature Size Matters**.
